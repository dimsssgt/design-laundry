# Laundyku — semua frame untuk v0

- index.html : daftar semua frame (landing sampai admin, termasuk pop up).
- frames/*.html : setiap frame sebagai HTML mandiri (tanpa runtime kanvas).
- assets/ : gambar hero yang dipakai landing dan login.

Setiap frame memakai path ../assets/ untuk gambar, jadi pertahankan struktur folder ini.
